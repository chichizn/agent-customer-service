# 商品知识与规则兜底

更新：2026-10-20。多平台工作台沿用“大模型优先、规则兜底”，本轮将集成知识从10条扩充到39条，优先解决普通问题缺少直接回答的问题。

## 现在如何回答

1. 绑定会话的商家、店铺和顾客，读取当前有效知识。当前明确提到的商品优先，否则使用前文商品线索。
2. 以一次有超时上限的模型请求分析场景、意图、情绪，并结合最近10条会话消息选择最多3条知识。返回知识编号后，后端再次校验店铺、商品、状态和有效期，直接输出已存答案。
3. 模型关闭、超时、格式异常或没有有效知识选择时，按同义关键词匹配兜底。订单、物流、工单仍查询业务服务；模型不能决定身份或凭空宣称业务成功。
4. 普通知识未匹配时请顾客补充具体问题，继续AI接待。明确要求人工、超额补偿及需要保护的业务写入降级时，继续使用原人工交接机制。

商家工作台“知识”页签显示最近一轮的场景、意图、情绪、分析及回答来源；执行记录保留对应步骤。顾客入口增加了常见问题快捷填入。

## 覆盖与试用问题

| 范围 | 可以直接试的问法 |
|---|---|
| 日常接待 | 你好，在吗？／谢谢／不用转人工／人工客服几点上班？ |
| 商品规格 | 保温杯有什么颜色？／保温杯容量多大？／收纳盒多大？／毛巾是什么规格？ |
| 清洗与使用 | 保温杯怎么清洗？／收纳盒怎么清洗？／毛巾第一次用要怎么洗？／杯子能装碳酸饮料吗？ |
| 售前与支付 | 有没有货？／保温杯多少钱？／怎么下单？／优惠券怎么用？／可以用什么付款？／支持开发票吗？ |
| 配送与订单操作说明 | 包邮吗？／什么时候发货？／发什么快递？／怎么修改地址？／怎么取消订单？ |
| 售后说明 | 怎么退货？／怎么换货？／退款多久到账？／退货地址在哪？／杯盖漏水怎么办？／漏发了怎么办？ |
| 店铺规则与活动 | 退货期限几天？／退货运费谁出？／收纳盒有什么优惠？／保温杯有什么优惠？ |

淘宝演示店退货期限为15天、抖店为7天，退货运费和活动也按各店资料回答。演示活动按项目的固定演示时钟判断；实际店铺政策不能直接套用演示答案。

“怎么退货”是流程咨询；“我想退货，原因是……”是业务诉求。前者直接回答流程，后者查询订单、补充原因并要求确认。明确“我要转人工”会交接；“人工几点上班”“不用转人工”继续回答问题。

## 数据更新与边界

集成种子位于 [knowledge.integration.v1.json](../../demo-data/knowledge.integration.v1.json)。启动新后端后，打开、恢复或发送会话消息会自动补入新增条目及缺失的匹配元数据，保留已有知识文案和状态，无需重置演示数据。修改种子中已有答案不会自动覆盖数据库里的同编号文案。

这些资料用于本地演示。真实商品材质、实时价格、库存、发货承诺、值班时间等需要商家提供，当前答案会说明如何确认，不能编造数值。一般清洗建议以商品洗标、说明书为准。平台消息、改地址、取消订单、退款到账等仍未接入真实平台执行。

原单平台知识中心的全局商品/FAQ管理接口仍保留；它没有店铺范围，当前不会自动同步进多平台范围知识。完整知识维护页面及有范围的发布流程仍待后续开发，不能将本轮种子扩充视为已完成该联动。

## 验证

后端测试覆盖两店常见问法、模型错误意图、语义选取、跨店/过期知识拒绝、商品指代、未匹配澄清及明确人工请求，同时回归订单与工单保护。检查器拒绝空、非文本及纯标点关键词、缺失商品别名。真实HTTP及页面证据见 [本轮验收](../acceptance/evidence/2026-10-20-run12/verification.md)。
