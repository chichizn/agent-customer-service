## 成片核验

建议完整录像 `customer-service-demo-YYYYMMDD.mp4`；仅前端模拟录像 `customer-service-frontend-mock-YYYYMMDD.mp4`。成片保存位置遵循团队约定，提供可访问位置和 SHA256，勿将未核实录像链接写成已有交付。

录后创建 `docs/demo/VIDEO-MANIFEST.md`：

| 字段 | 当前状态 |
|---|---|
| 文件/位置、录制者、时间/时区 | 未录制 |
| 类型：前端模拟 / 完整集成 | 待录制时明确 |
| commit、种子/知识摘要、日期策略 | 待实际录制填写 |
| 模型模式/名称（无密钥） | 待实际录制填写 |
| 分辨率、时长、SHA256 | 待成片填写 |
| 三故事、刷新、统一重置回看 | run11图文证据已核对；成片尚未录制，未进行视频回看 |

逐段回看：能正常播放、文字和声音清晰、编号前后一致、没有密码/API Key、本地诉求未被说成平台退款。
